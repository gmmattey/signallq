# Referência visual — SignallQ para Windows

Rascunho (ADR-023). Referência para o desenvolvimento do app Windows; **não é funcionalidade entregue**.

- `prototype/index.html`: protótipo navegável com dados simulados (abra pelo servidor local, por exemplo `python -m http.server` dentro de `windows/design`, e acesse `/prototype/index.html`).
- `tokens-windows.css`: tokens de cor, tipografia, espaço, forma e elevação, derivados do DS Android.
- `DESIGN_SYSTEM_WINDOWS.md`: especificação, regras e plano de adoção.
- `prototype/assets/`: símbolo da marca (`brand/`) e Google Sans Flex (SIL OFL, cópia de `android/app/src/main/res/font/`).
